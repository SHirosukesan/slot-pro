# データ確認手順

## 状態の付け方
| 状態 | 条件 |
|---|---|
| `verified` 確認済み | 独立した信頼できる情報源 2 つ以上で一致 |
| `single` 単一ソース | 信頼性の高い一次資料（メーカー公式等）1 つ |
| `needsReview` 要確認 | 情報源で数値が食い違う。多数決で決めない |
| `unverified` 未確認 | 出典が見つからない |
| `na` 該当なし | その仕組みが機種にない |
| `sample` 表示サンプル | STEP 1 の架空値 |

## 手順
1. 候補: ちょんぼりすた / DMMぱちタウン / なな徹 / P-WORLD / メーカー公式。
2. 正式名称・型式・数値・単位・リセット/据え置き条件・内部モード条件・解析更新日・URL を比較。
3. 該当記事・該当見出しの URL を `sources` に記録（トップページは不可）。参照日・確認日も記録。
4. 一致しても元情報が同じ可能性があるので、`note` に気付きを残す。
5. 自動取得は各サイトの利用規約で許可されている場合のみ。許可がなければ手動照合。有料サイトのスクレイピング・認証回避はしない。
6. `npm run validate:data` で `verified` なのに出典が 2 件未満などの警告を確認。
