# SLOT PRO

パチスロのハイエナ・ジグマ向けに、狙い目・天井・やめどき・朝イチ・有利区間を **3秒で確認** するための PWA。

> **現在 STEP 1（試作）** — 数値はすべて架空の「表示サンプル」です。実機の解析値ではありません。

## 起動

```bash
npm install
npm run dev          # 開発サーバー
npm run build        # 本番ビルド（PWA 付き） → dist/
npm run build:preview  # 1ファイルのプレビュー用ビルド → dist-preview/index.html
```

| コマンド | 内容 |
|---|---|
| `npm run typecheck` | TypeScript strict 型チェック |
| `npm run lint` | ESLint |
| `npm test` | Vitest（ロジック・データ・画面） |
| `npm run validate:data` | 機種データの形式検証のみ |

## 構成

```
src/
  types/machine.ts      データ型（機種・ルール・出典・店舗・空き台）
  data/
    machines/*.ts       機種マスター（1機種1ファイル）
    machines/index.ts   機種一覧（追加時はここに1行）
    schema.ts           Zod スキーマ
    helpers.ts          データ記述ヘルパー
    stores.ts           店舗・設置情報（構造のみ）
    sampleSlots.ts      期待値ランキングのサンプル
  lib/                  判定・表示形式・検索・有利区間・ランキング・保存・検証
  config/ui.ts          一覧の表示項目・詳細の表示順・入力ボタン
  styles/tokens.css     色・角丸・余白・文字サイズ・画像サイズ
  components/ui.tsx     共通部品（判定ピル・機種画像・入力シート等）
  screens/              クイック判定 / 機種詳細 / 期待値順 / 設定
  state/useAppState.ts  入力値の保存（localStorage）
public/machines/        機種画像を置く場所
docs/                   機種追加・データ確認・公開の手順
```

## 見た目の調整

- 色・角丸・余白・文字サイズ・画像サイズ → `src/styles/tokens.css`
- 一覧に出す項目、詳細の表示順・表示/非表示 → `src/config/ui.ts`

## PWA の注意
- iPhone は Safari の「ホーム画面に追加」でのみインストール可能。プッシュ通知等は使っていません。
- 機種情報はオフラインで表示できます。外部攻略サイトは通信が必要です。
